Finally for the recommender, we setup **recommender/`apps.py`** to ensure we train our models immediately our server is spawned on production ([Learn more about ready() and Django Signals](https://docs.djangoproject.com/en/5.0/topics/signals/)).

```python
from django.apps import AppConfig

class RecommenderConfig(AppConfig):
    default_auto_field = 'django.db.models.BigAutoField'
    name = 'recommender'

    def ready(self):
        from .views import train_model_init
        train_model_init() # Handle initial setup of model
```
